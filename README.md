# Computational Biology Portfolio

A curated collection of analysis pipelines, exploratory notebooks, and demonstration modules developed as part of my work in genomics, molecular evolution, and multi-omics data integration.

## Overview

This repository gathers stable, self-contained versions of computational biology projects. Each directory contains code, documentation, and example outputs that illustrate specific analytical workflows used in my research.

## Projects

* **Cilia_Clusters**
  Clustering and comparative genomics analyses for identifying evolutionarily conserved ciliary gene modules.

* **Heatmap_Visualization**
  Utilities and scripts for generating publication-ready heatmaps and similarity matrices from multi-omics datasets.

* **IRD_Phenotype_Clustering**
  Phenotype-based grouping and feature integration for inherited retinal disease genes.

* **IRD_LBS_Barcode_Segments**
  Local barcode segmentation and exploratory analysis pipeline (demo and synthetic examples only).

## Structure

* Each project folder contains standalone scripts, documentation, and representative output files.
* Lightweight exploration, quick prototyping, and intermediate steps appear in dedicated notebooks.

## Data Policy

All datasets in this repository are synthetic, transformed, or demonstrative. Original research data remain private to protect confidentiality and comply with institutional and collaborative agreements.

## Status

Work in progress. Additional modules, documentation, and polished examples will be added over time.
